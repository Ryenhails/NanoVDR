NanoVDR · DistilVDR · ColNanoVDR

Efficient visual document retrieval with small distilled encoders

NanoVDR is a family of small encoders aligned to the embedding space of a frozen vision-language retriever. A text encoder of 69M to 395M parameters answers each query, so pages indexed by a 2B to 8B model are searched without running that model per request. DistilVDR adds a 457M page encoder, which takes the large model out of indexing as well.

Zhuchenyang Liu, Ziyi Wang, Yao Zhang, Yu Xiao · Aalto University

Overview

A query is text. It does not need a vision model.

Visual document retrieval matches a text query against page images, with no OCR in between. The strongest retrievers are 2B to 8B vision-language models. Indexing a corpus with one is a one-time cost; running the same model on every query is a cost that never stops. Each NanoVDR paper moves a different part of that work onto a small student.

Grey blocks are multi-billion vision-language models. Tinted blocks are NanoVDR students.

One loss, no labels

Each student minimises a direct discrepancy to cached teacher embeddings. No relevance labels, no hard-negative mining, no contrastive sampling.

Encoders train alone

An encoder only sees its own cached targets, so a query encoder and a page encoder can be trained separately and paired afterwards.

Works with the teacher's index

A student lands in its teacher's space, so it scores an index the teacher already built. Teacher and output width must match.

Deployment

Pick the pair that matches your index

A query encoder and a page index work together when both target the same teacher at the same output width. The model name says which.

[Col]NanoVDR-<Q|D>-<variant>-<teacher>-<width>[-ML]

Col marks a multi-vector model. Q or D says which side it replaces. Teacher and width fix the embedding space; -ML means it was trained on the multilingual mixture.

Quick start

Load from the Hub

Every checkpoint loads with sentence-transformers and has no dependency on the NanoVDR repository.

from sentence_transformers import SentenceTransformer

query = SentenceTransformer("nanovdr/NanoVDR-Q-DistilBERT-Qwen3VL2B-2048-ML")
q_emb = query.encode(["What was the revenue growth in Q3 2024?"])   # (1, 2048)

scores = q_emb @ doc_emb.T   # doc_emb: pages indexed by Qwen3-VL-Embedding-2B
from sentence_transformers import SentenceTransformer   # >= 5.4 for the page encoder

query = SentenceTransformer("nanovdr/NanoVDR-Q-DistilBERT-Qwen3VL8B-4096-ML")
doc = SentenceTransformer("nanovdr/NanoVDR-D-HiRes-Qwen3VL8B-4096", trust_remote_code=True)

scores = query.encode(["..."]) @ doc.encode(pages).T   # pages: PIL images
from sentence_transformers import MultiVectorEncoder   # >= 6.0

query = MultiVectorEncoder("nanovdr/ColNanoVDR-Q-Ettin150M-ColQwen35-320-ML",
                           trust_remote_code=True)
q = query.encode_query(["What was the revenue growth in Q3 2024?"])

scores = query.similarity(q, page_embeddings)   # meanMaxSim, pages from the teacher

Pass the raw query. Do not add an instruction prefix. The teacher's instruction was applied when its targets were cached, and every published number was measured on bare query text.

FAQ

Common questions

Can visual document retrieval run on a CPU?

The query side can. The 69M NanoVDR query encoder answers a query in 51 ms on one CPU thread. Pages are still encoded once, offline, on a GPU, either by the teacher or by a NanoVDR-D page encoder.

Can I keep my existing ColPali-style index?

Yes, if one of the supported teachers built it: ColQwen3.5-4.5B, Vultron-4.5B, Tomoro-8B, ColVec1.1 4B or 8B, or EVIE 4.5B or 8B. The matching ColNanoVDR query encoder emits token vectors in that teacher's space, and the index is scored by MaxSim unchanged.

Do I need relevance labels or hard negatives to train one?

No. Every encoder is trained against cached teacher embeddings with a single alignment loss. ColNanoVDR also needs no page images: it only consumes the teacher's cached query token embeddings.

Which languages are supported?

The -ML models were trained on English plus five Latin-script European languages, translated with MarianMT. Non-Latin scripts are untested.

Which model should I start with?

For a single-vector index built by Qwen3-VL-Embedding-2B, NanoVDR-Q-DistilBERT-Qwen3VL2B-2048-ML. For a deployment with no large model at all, the DistilVDR pair. For a ColQwen3.5 multi-vector index, ColNanoVDR-Q-Ettin150M-ColQwen35-320-ML.
